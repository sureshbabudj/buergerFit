# BürgerFit Release Notes

## v1.0.0 (2025-07-02)

### Initial Release
- Comprehensive quiz app to prepare for the German Einbürgerungstest (naturalization test)
- Dual language support: German and English
- Two-part structure: General civics and regional/state-specific questions
- Interactive quiz interface with immediate feedback
- Progress tracking and analytics for attempted questions and results
- Responsive design for desktop and mobile
- Dark and light theme support
- Mobile-optimized navigation drawer
- Real-time feedback with toast notifications
- Visual answer highlighting for correct/incorrect responses
- Easy navigation between questions and sections
- Attempt history and performance analytics
- Regional focus for Teil 2 (state-specific questions)
- PWA support: installable, offline-ready, and with manifest screenshots
- Accessibility improvements and modern UI

Thank you for using BürgerFit! Your feedback is welcome to help us improve the app further.
